### 컴포넌트(Component)

- UI를 구성하는 가장 작은 단위이자, 재사용 가능한 독립적인 블록을 의미

- 컴포넌트 정의 방법

  - 클래스형 컴포넌트
    - React.Component를 상속받아 만들며, render() 메서드 안에 JSX 반환
  - 함수형 컴포넌트
    - 함수로 정의하며, props를 받아 JSX로 반환

- 컴포넌트의 공통적인 특징

  - JSX를 리턴

- 클래스 컴포넌트는 리엑트 초창기부터 존재했던 방식 (2019년도 2월까지 사용)
- 함수형 컴포넌트는 리엑트 0.14버전(2015)
- 리엑트 훅 덕분에 함수형 컴포넌트 사용 ⬆️

### JSX

- 문법적 설탕
- JS + XML 확장 문법으로 자바스크립트 안에서 HTML과 비슷한 구문을 쓸 수 있게 해주는 확장 문법

- JSX의 특징
  - 반드시 하나의 루트 태그를 가져야만 한다.
  - 여러 줄을 리턴할 때는 소괄호(필수, 권장)
  - HTML4 <-> HTML5 (\<br>이 권장사항)
  - 태그의 '속성'은 카멜케이스(camelCase)로 작성한다.
  - class는 className, for은 htmlFor

### 컴포넌트

### 스타일링

- 인라인 스타일: style 속성으로 지정하는 방법 (메일 안의 스타일은 인라인 스타일만 가능함)
- 외부 스타일: 별도의 CSS 파일에 CSS 코드를 작성하고, 리엑트 컴포넌트 파일과 연결해서 사용하는 방법
- CSS 모듈 (\*module.css)

- Tailwind CSS
- CSS-IN-JS

- 모듈 css 파일에서 클래스 선택자만 사용한다.
